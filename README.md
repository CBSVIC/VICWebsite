# CBS Value Investing Club Website

This repository contains the website code and supporting scripts for the CBS
Value Investing Club (CBS VIC). It is the home for developing and maintaining
the club's website.

## AI-assisted development

AI assistants working in this repository must follow the safeguards in
[`.github/copilot-instructions.md`](.github/copilot-instructions.md), including
human review of AI-generated investment-related content before publication.

## Getting started

Clone the repository and move into the project directory:

```bash
git clone https://github.com/CBSVIC/VICWebsite.git
cd VICWebsite
```

The repository currently contains this README. Setup and run instructions will
be added here when the website source code and its tooling are in place.

## Contributing

Keep website code and related scripts in this repository. When adding or
changing project tooling, update this README with the required setup and
commands for running, testing, and building the website.
